# Bayes Theory Tattoo Design

This is a personal project that generates the 
tattoo I got representing a 1D Bayesian inference. 
The design shows three Gaussian distributions, 
a prior, an observed likelihood, and the posterior.

# Meaning

I obviously liked this enough to get it put on my
body, but if you're interested in learning more 
about why I got it, or more about Bayes theorem, 
shoot me an email! I'd love to talk.

Also, as a fun side thing, my thesis has to do 
with Bayes' Theorem, so this is serving as a fun
exercise for trying to intimitely understanding 
how this theory is applied, and having a close
connection with my own tattoo.

## Overview

This repo contains three main files:

"code.py" | My hand-coded script generating the final "tattoo.png"
"ai_parameter_script" | An AI-written tool to explore parameters in real time
"document.tex" | My LaTeX derivation of the math behind these plots

The repo also is a personal exercise in deriving
how Bayesian inference works to strengthen my
understanding of it. I wrote "code.py" by hand,
unassisted by AI for personal reasons, while the
"ai_parameter_script.py" was built with AI just
to quickly figure out what parameters made the
tattoo look just right.

I hope you enjoy seeing this, learning a bit about
me, and a bit about Bayesian inference.
